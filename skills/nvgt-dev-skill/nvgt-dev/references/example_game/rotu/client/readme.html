1. What is ROTU?

1.1. Story behind the Game

A man, by the name of Kyle, sought revenge for the loved ones he had lost. First his wife, then his children. His only sister, Emily, faded along with them. He was alone.
He wanted to cause pain to the world. He was tired of all the pain that he was bearing. He began performing rituals, resurrecting animals who had died long ago, shaping them into his own cold imagination. The Gholion, a skelletal lion. The Giabear, the gigantic reanimation of a black bear. The Agawolf, a wolf who had been chained and tortured to death. And the Ghostkey, the monkey who had been locked in a cage for years, with no food or water.
There was a risk, however, by reviving these long-dead animals. It had also brought back other unknown forces and mythical creatures. But Kyle didn't care. He wanted to cause as much pain as possible.
As cold as this man's imagination was, however, the animals soon turned on him. They also wanted revenge for their torture, their agony, their imprisonment. So, the animals rampaged throughout the world, causing destruction. As players, you are attempting to put the animals back into the world of the dead. But since the animals are already dead, they keep reassembling and reappearing. And it's only a matter of time, before the world falls...

1.2. Description

ROTU is a 3D multiplayer based FPS in which your goal is to kill the ghost animals that await to tear you apart. However, it won't be easy.
As you kill the animals, you gain gold, which can then be used to buy stronger weapons and equipment to protect yourself.
You can also participate in player held events, which allow you to get even more gold and to improve your fighting skills.

2. Opening and Setting up the Game

To launch the game, locate the rotu.exe file in the game's directory and press Enter.
If the game's language is not set yet, you will be prompted to select a language. Use the arrow keys to select a language from the list, then press Enter to choose that language.
I am always looking for language improvements, so if you speak a certain language and notice something is incorrect, or you want to provide a translation for your language, do not hesitate to send me a fixed / new translation file. Translation files are found under translations/language_name.txt, where language_name represents the language.
The game will check for updates at startup. You can disable this option under Game settings, though it is recommended that you leave this option on. You will then be presented with the main menu.

2.1. Main Menu

The Main Menu is fairly simple. Use your arrow keys to select an option, then press the Enter key to activate it. The following options are available.

  • Login menu: Takes you to a menu where you can login, create a new account, or setup an existing account.
  • Test speakers: Test your speakers to be sure they are configured correctly.
  • Learn game sounds: Allows you to learn the various sounds used in-game.
  • Game settings: Allows you to configure more options and customize the game to your liking.
  • Check for updates: Checks to see if there are any game updates. If there are any, you will be prompted, and asked if you would like to download the update. Selecting Download update will initiate the download, and selecting Don't download will return to the main menu.
  • Exit: Quit the game and return to reality.

2.2. Settings menu

The settings menu is divided into submenus for easily customizing certain aspects of the game.
You can cycle between the available submenus by using the Left and Right arrows, and you can see the available items with the Up and Down arrows. Depending on what submenu is selected, the menu items will update to match the selected submenu.
The user interface menu is geared towards language settings, menu related settings, and startup settings, while the game settings menu is geared towards more in-game elements. The text-to-speech section is for SAPI users. If you need any assistance in figuring out what the settings do, do not hesitate to contact an admin or developer in the game, or to ask players for support.

3. Gameplay

Before you can start playing the game, you must create an account. The process is fairly simple, you just need to provide a username and a password.
Keep in mind that if you receive an error telling you the creation process failed, it could be one of the following reasons.

  1. You were banned.
  2. Error connecting to the server.
  3. A player with the specified name already exists.

If you believe it is a different reason, please contact me, found at the bottom of the readme.
When you start out in the game, you will be placed in the character menu. In this menu, you can select a character you already own, or you can create a new one using the create character option.
If you log into a character for the first time, you will be placed in the Character Lobby. This lobby is a simple 10x10 map with a table and some chairs, for those who would rather use their character to socialize on the game rather than play it.
If, however, you want to play the game using the character, you can go to 10, 10, 0, and press Shift Enter. Note that once you do this, you cannot come back to the Character Lobby anymore! So it's up to you to decide whether that character should be for gameplay or not.
Once you are in the game, you will be in the safe zone. The following commands are available.
Keep in mind that this game supports both keyboard and mouse.
Keyboard commands:

  • Arrows: Move in the corresponding direction.
  • G: Use the camera. While G is held down, you can move the camera around using the arrows. For people with dexterity issues, you can lock the G key down by pressing the Grave key, this toggles a feature called Dexterity Camera Mode (DCM).
  • G plus D: Check which tile the camera is located.
  • G plus Z: Check the camera's zone.
  • G plus Backslash: Toggles Move Focus with Camera on or off. Move Focus with Camera, or MFWC, allows you to view your surroundings through the camera's perspective. As you move your camera around, your view will update to match the camera's view.
  • Q and E: Rotate 45 degrees.
  • T: Brings up a menu to track players.
  • W: Tells you where a tracked player is.
  • F: Check facing.
  • Space: Jumps.
  • U: If you are sitting, gets into a crouching stance. If you are crouching, you will stand up.
  • J: If you are standing, gets into a crouching stance. If you are crouching, you will sit down.
  • C: Check cordinates.
  • V: Check clothes. Clothes are extra, they do not actually offer any sort of upgrade, simply there for customization. You can find them at the store.
  • Z: Check location.
  • H: Check health.
  • Page up and Page down: Climb up and down where possible.
  • Home and End: Adjust music volume, if there is music on the map.
  • Dash and Equals: Adjust game master volume.
  • Number row: Select weapons.
  • Left or Right control: Fires selected weapon. Keep in mind that if you have the Right Control key disabled under settings, it will simply serve as an alternative to stop speech / do nothing.
  • R: Reloads a weapon.
  • A: Check ammo in the selected weapon.
  • Tab and Shift tab: Cycles through items in your inventory.
  • Enter: Use an item from your inventory.
  • I: Open your inventory menu, to navigate through items easier.
  • Semicolon: Move to the previous inventory menu category.
  • Apostrophe: Move to the next inventory menu category.
  • Shift Enter: Activates other map elements, such as travelpoints, event participation, doors, signs, picking up items, etc.
  • X: Check how much experience you have, as well as your rank.
  • M: Checks to see if there are map beacons. If there are, you can track them in the menu which is presented to you. You can then either track a map beacon by following the beeping (the closer you are the faster it beeps), or press N.
  • N: Check where a beacon is, as well as your average distance away from it. This is average because beacons will not always be 1 tile in length and width. When this is the case, the game adds both the minimum and max values and divides them by 2 to achieve an average middle.
  • K: Brings up a menu to track items that are near you. If an item is within a 35 tile radius, it will appear in the menu. There is also an option to stop tracking the selected item.
  • L: Check where the tracked item is. When you reach the item you can press Shift Enter to pick it up.
  • Comma and Period: Move through items in a buffer. Combining with shift will jump to the first or last item in that buffer.
  • Left and Right bracket: Change buffers. Combining with Shift will jump to the first or last buffer.
  • Shift C: Copies a buffer item to your clipboard.
  • Alt Enter: If there are links in a buffer item, allows you to open them in your default web browser directly from the game. If there is more than one link, you will be presented a menu allowing you to choose a link to open. Otherwise, opens the only link available.
  • Slash: Chat or use server commands. For a list of server commands, type /help into the chat box.
  • Shift Slash: Check who is online.
  • F1: Players menu. Combining with Shift will toggle player beacons.
  • F2: Server stats.
  • F3: Ping the server to test lag.
  • F4: Server Message. This was previously Message of the Day, but since I felt the message wasn't always changed daily, it would be better to call it Server Message.
  • F5: Language channels menu.
  • Escape: Exits the game. Combining with Shift will disconnect and reconnect to the game, as if you had hit Escape, then chose Login from the main menu.


Mouse commands:

  • Right click: Move in the specified direction.
  • Left click: Fires selected weapon.
  • Click scroll wheell inward / middle click: Reloads your weapon.
  • Move mouse horizontally: Change direction.

3.1. Gameplay in more Detail

The game takes place on the main map, which is a 500x500 grid. It is a ruined city, and it has several abandoned buildings. Thanks to the builders, Blind Lightning and Pool (and I also contributed a bit as well), we based the map mostly off of the story. For more information about the different main maps, see the map descriptions documentation.
To reload your weapon, press the R key, or if you are using the mouse, click the middle button, or also known as the scroll wheel, inward. During this process you cannot fire or draw any other weapon.
When you kill undead, you will gain gold. This gold can be used at the store.
Sometimes undead will also have other rewards. An example is the graven. When you kill a graven, you have a chance of gaining a graven feather. A graven feather is a feather which has some magical abilities, and that's why it is so rare. Get 1000 of these feathers, and you will unlock something. I'll leave it to you as the player to find out what it is, but it is worth it.
The store is in the abandoned outpost, , which is located at 30, 73, 0, on main1 (default map). Once you are in the outpost, press Shift Enter to open the store menu.
The store offers extra weapons, ammo, healing items, and also armor.
Each time you kill undead, you gain experience. When you have a certain amount of experience, you increase your rank. The following ranks are available, with their experience points listed next to them.

  • Apprentice: 0
  • Junior Apprentice: 500
  • Senior Apprentice: 1000
  • Trainee: 1500
  • Novice: 2000
  • Specialist: 3000
  • Arch Specialist: 4000
  • Master: 6000
  • Arch Master: 8000
  • Warrior: 10000
  • Arch Warrior: 15000
  • Sage: 20000
  • Arch Sage: 30000
  • King's Guard: 50000
  • King's Adviser: 60000
  • Hand of the King: 75000
  • King: 100000
  • High King: 115000
  • Emperor: 125000
  • General: 150000

Each time you level up, the server will be notified of your accomplishments. As you can see, the levevl up process gets harder and harder the better you get.

3.2. Armor

Once you get enough gold, you can start purchasing armor to lessen the damage that animals deal to you.
Leather armor reduces damage by 20, chainmail armor reduces damage by 36, and plate armor reduces damage by 40.
There are other types of armor, which are available in the store. These pieces of armor do not lessen the damage as much as leather armor, chainmail armor or plate armor, but combine with the armor to make heavier defense. For example, a steel helmet, plus plate armor, plus combat boots, reduces damage by 68 health.
To wear armor, cycle to it in your inventory, then press Enter. You should hear "You wear the XXX", where XXX represents the type of armor you are wearing.
To check your armor, press H. It will be announced after your health.

3.3. Weapons

The default weapons can begin to get old and boring. To solve this, you can buy more weapons at the store. An example is the Micro SMG, which allows you to take out masses of undead with ease.
Some store weapons also have more capabilities than the default weapons. For example, the Micro SMG has a burst fire mode, which can be activated by pressing S. This applies to any other weapon that has an extra feature.
There are more weapons coming in the future, but if you have any recommendations or weapons of your own to add, let me know.

3.4. Capture the Flag

As of 0.2.5, you are now able to play CTF against other players.
To start a game of CTF, first create one by accessing the safe zone menu, which can be done by pressing Shift Enter. Then, choose Create a CTF event from the list of options.
You can also join an existing CTF event by choosing Join a CTF event from the list.
Once in a CTF event, you can start or cancel it, if you are the creator of the event, switch teams (between green and red), and also check the members of the event by typing /ctfmembers in chat. You can communicate with your teammates by typing /t message in the chat box.

3.4.1. Capture the Flag map

The Capture the Flag map is a 100x150y grid.
On both the north and south sides, there is a fence holding up two towers, which have small doors that can be used to access the towers. Each tower has a hole blown into them, which can be found by following the zones indicated to you by your screen reader.
For the red team, the western tower is on the west side, and the eastern tower is on the east side. For the green team, this is reverse.
Both fences have a small gap which you can run through. However the goal was to make it so that playing the event would be hard. So, in the middle of the map is a large hill. This hill runs all the way across the map on the x axis.
On both sides of the map (north and south) are zones. The south zone is for the red team, and the green team is on the north side.
On both zones there are flag holders. The red zone's flag holder is at 50, 25, 0, and the green zone's flag holder is at 50, 125, 0.
If you are on the green team, your goal is to run south, grab the red flag from the red zone's flag holder, then run back to the north side and deposit the flag onto your team's holder.
If you are on the red team, your goal is to run north, grab the green flag from the green zone's flag holder, then run back to the south side and deposit the flag onto your team's holder.
Although this sounds easy, players are able to locate and stop you from taking the flag back. So be careful, and stay alert!
You can press Shift F1 to toggle player beacons on and off. This will make it easier to decipher who is friend and who is foe.
The first team to reach 10 points wins the game, and receives a random amount of gold between 25 and 100. The team that loses receives a nice pat on the back.

3.5. Cars

Cars help you get around the map more efficiently and speedily. The car used in this game is called an Auto Saturn, a car created by the Saturn Corporation back in the 1980s. Yes, I know, its old, however, its the best one I could find.
To buy an Auto Saturn, you must access the store found in the safe zone. Auto Saturns cost 1750 gold, and repairations for car damage cost 875 gold.
You can repair your car by heading to the safe zone workshop, found north of the safe zone. Rather than going through the entrance, instead head around the safe zone and head north until you find the workshop, which is attached to the safe zone. Once inside, cycle to the broken auto saturn item in your inventory and hit Enter. 875 gold will be taken from your inventory, as well as the broken auto saturn, and it will be replaced with a fixed up version.
Once you have the car, you can press Enter on it to start its engine.
While you are in the car, you cannot jump, walk, or climb. Instead you may do the following.

  • Up arrow: Increase speed. Drivable speeds are 1, 2, and 3.
  • Down arrow: Decrease speed. 0 is the slowest speed. In fact its not a speed at all, it makes your car idle.
  • Left arrow: Turn your car 90 degrees left.
  • Right arrow: Turn your car 90 degrees right.
  • Space: Honk the horn.
  • Escape: Get out of the car. The car needs to be idle(at speed 0) in order for this to work.

Keep in mind that if you are approaching a wall, your car will begin to warn you with audible beeps. If you get within 3 tiles of the wall, your car will crash, and you will gain a broken auto saturn. This is what you take to the workshop to be repaired.

3.6. Dragon

As said in the story, by reviving some animals, Kyle also brought back some other dangerous mytical forces. The black dragon, is a large, dangerous creature that has lots and lots of health, and it will occasionally spawn on the server.
The dragon only spawns when there are 2 or more players online. During this time the dragon is able to fly or land to find players.
Armor does not block dragon attacks, so you need to be very careful.
The person that ends up killing the dragon gains between 50 and 500 experience and gold.
Good luck!

3.7. The mPad


The mPad is a tablet that allows you to buy, transfer, and communicate with others.
The mPad can be purchased at the store.
Once you have the mPad, the tablet will already come with a battery pre-installed. However, once you drain the battery, you will need to buy a new battery pack, also buyable from the store.
To power on the tablet, find it in your inventory, then press Enter. The tablet will start up, and the home screen will be displayed in the form of a menu. You can then cycle between the home screen options.
At the top of the device will be the battery status. This tells you the percentage, and an average duration of which the battery can continue running. You will also find the digital clock, which will display the game's current time. For reference, 0.2 seconds (200ms) in real life is 1 second in the game, meaning 12 seconds is one minute, and 12 minutes is one hour. 4.8 hours in real life is 1 day in the game.
You will also find the Item Transfer status. This works as a toggle, on or off. More about item transferring in a bit.
Finally you will find 4 other apps. Online Store, Walkie Talkie, Gold Flip, a simple coin toss game to kill boredom, and iRoll, a fun dice game.

3.7.1. Item Transfer

Item transfer allows you to transfer items to other players.
In order for item transfer to work, the following requirements must be met.

  • The mPad that you are trying to transfer to, must be turned on. This means that the player you are trying to transfer to, must own an mPad. You should also have your mPad enabled also.
  • Item transferring status must be enabled on both devices.

Once these requirements are met, you can then type into the chat, /transfer playername itemname amount. Assuming everything is met above, the item quantity specified will be taken from your inventory, and transferred to the other player.

3.7.2. Walkie Talkie

The walkie talkie allows communication with people who are on your map.
To enable the walkie talkie, activate your mPad's home screen, and then choose Walkie Talkie.
On the next menu, select the channel that you would like to use on your walkie talkie. There are 99 channels available, plenty for everyone.
To disable the walkie talkie, rather than choosing a channel, choose disable.
Keep in mind while utilizing the walkie talkie, the mPad will drain more battery, as it is using Bluetooth technology.
To use the walkie talkie, type /m message, and who ever is on the map will hear your message, as long as you and the player you are communicating with are on the same channel.
You can also use O to do the same thing, as a sort of shortcut.

3.7.3. Client-side Apps

So far, the features we have discussed all operate on mostly the server, using menus and such. However, iRoll and Gold Flip utilize client-side keyboard commands.
Gold Flip is simply a coin tossing game. It doesn't really have any value whatsoever, simply to kill boredom.
iRoll, however, is a dice game which will actually reward you for playing.
iRoll allows you to roll all of the same number, and get 10 gold times the amount of dice you ended up doing it with. For example, if I rolled 3 dice, and got 3 4's, then since I used 3 dice, 10 times 3 is 30, so I get 30 gold.
You cannot get any reward for only using one die!
Keep in mind while using mPad client-side apps, not all game keyboard commands will work. Only the following commands listed below will be functional.

  • Slash
  • Comma
  • Period
  • Left Bracket
  • Right Bracket
  • P
  • Escape, to close the application
