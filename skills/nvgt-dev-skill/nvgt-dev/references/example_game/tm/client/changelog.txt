Okay, never expected to say this, but the entire game got recoded. Everything, from weapons to creatures has been recoded, and is improved and bug free now. The changes will be mentioned below.
Voicechat is in the game now! Hold down the v key, record your message, release the key and boom! Your message will be heard by people in the range of 50 tiles.
Now you can easily switch layouts! To do this, press alt shift. Yes, now the keyboard layouts are switched in a system way, that is, you will have such layouts that are installed in your system!
added weapon slots on the number keys. now if you draw a weapon from your inventory, you will be able to draw it again from the number keys. this way you will have a bunch of weapons ready to be used without going through inventory or favorite items.
Increased security.
M116 death bringer is back! However now, it requires bullets.

Added guided missiles! It is an item which you can use to target specific players, or specific coordinates.
Added missile interceptors.
Added the resurrection system. Now when your levels go above 1500, they will automatically be reset to one. In addition, you will gain a permanent +one million health. For example, a person gaining a rez for the first time would get his health from 50 million to 51 million, which would be permanent. Credit goes to the game constant battle, from which the idea has been taken. 
Alert. All the levels of the players have been reset to 1, so that the rez system may work without any bugs.

Recoded the favorite item system. Now, you use the favorite items with alt and the number keys. Putting favorite items is still on shift and numbers. The normal numbers work with your weapons. Whenever you draw a weapon from your inventory, it automatically gets on a number so you may use it quickly.
Added stereo typing! Press f4 to enable or disable it while in the chatbox!
Now when you open a chatbox you can navigate through words by pressing control with left or right arrow keys.
Now alliances members can be hurt by each other if in arena.
Added vanishing platforms! These platforms will only be there on map for a specific duration, and then they will disappear! So be careful!
Added checkpoints to the builder menu. If you encounter a checkpoint and die afterwards, you'll be revived back at the checkpoint's location.
Added clocks and calendars.
Recoded the backup system. Now instead of backing up inventories the game will automatically back up all the players.
Recoded health boosters. Now you can use only ten of them in a single life. After that they stop working. To use them again you must use /suicide or someone must kill you.
Fixed the bgt runtime errors with creatures. Here’s to hoping the server won't crash so frequently now.
